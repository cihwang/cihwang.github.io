글쓰기 문법을 한 장에 모았어요. **회색 상자 안이 쓰는 법**, 그 아래가 실제로 보이는 모양이에요.
내 컴퓨터 미리보기(`python serve.py`)에서 어느 화면이든 **`?` 키**를 누르면 이 창이 떠요. 사이트 방문자에게는 보이지 않아요.

## 1. 새 글 만들기

`posts/_템플릿.md`를 복사해서 `posts/날짜-제목.md`로 저장하고, 맨 위 네 줄을 채워요.

~~~md
---
title: 휠을 만들며 배운 것
category: 만든 것
date: 2026-10-20
draft: true
---
~~~

| 항목 | 뜻 | 꼭? |
|---|---|---|
| `title` | 글 제목 | 필수 |
| `category` | `글` · `공부` · `만든 것` · `취향` 중 하나 (`site.json`에서 바꿔요) | 필수 |
| `date` | `YYYY-MM-DD`. 최근 글 순서와 휠 위 순서가 이걸로 정해져요 | 권장 |
| `draft` | `true`면 초안: 미리보기에만 보여요. 다 쓰면 줄을 지워요 | 선택 |
| `slug` | 주소에 쓰일 이름. 없으면 파일 이름에서 날짜를 뺀 것 | 선택 |

## 8. 코드

한 줄 안의 코드는 백틱 하나: `` `requestAnimationFrame` `` → `requestAnimationFrame`

여러 줄은 백틱 세 개로 감싸고, 바로 뒤에 언어 이름을 쓰면 색이 칠해져요.

~~~md
```js
// 가운데 눈금을 잎색으로
const glow = centerGlow(f, st);
requestAnimationFrame(step);
```
~~~

```js
// 가운데 눈금을 잎색으로
const glow = centerGlow(f, st);
requestAnimationFrame(step);
```

자주 쓰는 언어 이름: `js` `ts` `jsx` `tsx` `html` `css` `json` `bash` `python` `java` `apex` `sql` `yaml` `md`. 모르는 이름이면 색 없이 보여요.

## 18. 미리 보고 올리기

1. `python serve.py`를 켜 두고 http://127.0.0.1:5173 을 열어요. 글 파일을 저장하면 새로고침만으로 반영돼요(초안 포함).
2. 맨 위 정보가 틀리면(카테고리 오타 등) 서버 창에 어느 파일이 왜 틀렸는지 나와요.
3. 다 쓰면 `draft: true` 줄을 지우고 커밋·푸시하면 사이트에 올라가요.
